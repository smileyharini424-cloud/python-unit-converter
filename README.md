# Unit Converter

## Explanation

The Unit Converter is a menu-driven Python program that converts values between different units of length, weight, and temperature.

## Problem Statement

Create a Python program that allows users to select a conversion category and convert a value from one unit to another.

## Features

* Length conversion
* Weight conversion
* Temperature conversion
* Menu-driven interface
* Input validation
* Supports multiple conversions

## How It Works

1. Select a conversion category.
2. Select the source and target units.
3. Enter the value.
4. Apply the appropriate conversion formula.
5. Display the converted value.

## Technologies Used

## Program Flow

```text

  ↓

Select Units
  ↓
Enter Value
  ↓
Perform Conversion
  ↓
Display Result
  ↓
Return to Menu
  ↓
Exit
```

## Sample Input

```text
===== UNIT CONVERTER =====
1. Length
2. Weight
3. Temperature
4. Exit

Enter your choice: 1
Enter value in kilometers: 5
```
